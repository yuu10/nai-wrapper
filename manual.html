1. 使いはじめ

  • 起動すると、NovelAI の画像生成ページが開きます。ログインはふだんどおりです。ログイン状態は、このアプリ専用の保存領域に残ります(ふだん使っているブラウザとは別です)。
  • 生成の設定(モデル・ステップ数・サイズなど)は、ブラウザ版とは別です。アプリで生成が遅いときは、まず設定をブラウザ版と同じにそろえてください。
  • NovelAI 以外のリンクは、既定のブラウザで開きます。
  • 「表示」ツールチップ: 画面の左下に、メニュー「View」と同じ操作(再読み込み・強制再読み込み・実際のサイズ・拡大・縮小・全画面)のボタンが出ます。ヘッダーには、いまの拡大率(例: 120%)が出ます。メニュー・キー・マウスのホイールで拡大率を変えても、数字は追いかけます。ヘッダーをドラッグすると、好きな位置に動かせます(窓全体に対する割合で覚えます)。ヘッダーの「－」「＋」で、最小化・展開できます。強弱などのチップとは、別のものです。メニュー「View → 「表示」ツールチップを表示」で、表示のオン・オフを切り替えられます(メニュー「View → パネルを右下にまとめ直す」で、位置が初めに戻ります)。
  • メニューは、ふだんは隠れています。Alt キーだけを押して離すと、画面の手前にポップアップで開きます(メニューバーを出さないので、窓の中身は動きません。Alt と別のキーを一緒に押したときは、開きません)。メニューのショートカット(Ctrl+R など)は、そのまま使えます。macOS では、画面の上のバーに出ます。

2. CSV 自動生成

CSV に書いたプロンプトを、1 行ずつ順番に生成します。1 行が 1 回の生成です。サイズ・モデルなどの条件は、今の画面のままです。

使い方

  1. 画面を、固定したい条件(メインのプロンプト、サイズ、モデルなど)にします。
  2. メニュー「自動生成 → CSV を読み込んで生成…」で、CSV を選びます。
  3. 件数の確認が出るので、「開始」を押します。
  4. 止めるときは、「自動生成 → 停止」です(実行中の 1 枚が終わってから止まります)。
  5. いったん休みたいときは、「自動生成 → 一時停止」です(下の「一時停止と再開」を見てください)。

連続生成(CSV なし)

CSV を使わず、いまの画面の設定のまま、「生成」を繰り返します。「自動生成」パネルの「連続生成」に、次の 2 つを入れて、「連続生成を開始」を押します(メニュー「自動生成 → 連続生成を開始」でも始められます)。

  • 最大回数: 1〜9999 回。
  • 連続上限: 1〜180 分。

この 2 つのうち、どちらかに先に達したら止まります(時間の上限は、生成中の 1 枚が終わってから止まります)。そのほか、次のときも止まります。

  • Anlas を消費する表示になったとき(メニュー「自動生成 → Anlas を消費するときは止める」がオンのとき。既定はオン)。
  • 画面にエラーが表示されたとき(メニュー「自動生成 → 画面にエラーが表示されたら止める」がオンのとき。既定はオン)。
  • 「停止」を押したとき(パネルの「停止」か、メニュー「自動生成 → 停止」)。

一時停止と再開

CSV 自動生成・連続生成の、どちらでも使えます。パネルの「一時停止」か、メニュー「自動生成 → 一時停止」を押すと、次の回に進む前で止まります。生成中の 1 枚は、終わるまで待ちます(その間、ボタンは「一時停止待ち(取り消す)」になり、押すと取り消せます)。止まっている間にプロンプトや設定を直せます。もう一度押す(ボタンは「再開」、メニューは「再開」)と、続きの回から始めます。

  • 止まっている間は、経過時間も連続上限の時間も進みません。
  • 止まっている間に「停止」を押すと、そのまま終わります。
  • CSV 自動生成で止まっている間に、画面のプロンプトなどを書き換えても構いません。ただし、次の行を始めるとき、CSV に書いた列の内容で上書きされます(空欄の列は、いまの画面の内容のままです)。

「自動生成」パネルは、上から、進み具合、「一時停止」と「停止」(進み具合のすぐ下に横並び。どちらも CSV 自動生成にも効きます)、「CSV 自動生成」(CSV の行ごとに、プロンプトを変えて生成)、「連続生成」(いまの画面の設定で、くり返す)の順に並びます。

完了したときも、止まったときも、デスクトップ通知を出します(メニュー「自動生成 → 終わったとき、窓が裏にあれば通知する」がオンのとき。窓が裏にあれば、タスクバーの点滅もあります)。パネルには、進み具合(○ / ○ 回)、経過時間と上限、終わるまでの目安が出ます(バーは、回数と時間のうち、上限に近いほうを表します)。入れた回数と上限は、覚えています。

Anlas を消費する場合があります。最初は、小さい回数(たとえば 3 回)で試してください。

パネル(進み具合・生成時間・入力補助)

画面の右下に、6 つのパネルが出ます。ヘッダーの「－」で最小化、「＋」で開きます。パネルは、それぞれ別々に動かせます。ヘッダーをドラッグすると、そのパネルだけが離れて、好きな位置に置けます(動かした位置は覚えています)。メニュー「View → パネルを右下にまとめ直す」で、すべて右下に戻ります。窓が低くて収まらないときは、右下のまとめた部分がスクロールできます。自動生成が終わったとき、アプリが別の窓の後ろにあれば、タスクバーのアイコンが点滅して知らせます。表示のオン・オフは、メニュー「View」にあります(パネルごと)。

  • 自動生成: 進み具合(○ / ○ 件、進捗バー、経過時間、残りの目安)を表示します。「CSV を読み込んで生成…」「一時停止」「停止」「Anlas を消費するときは止める」も、ここから操作できます。最小化しても、件数と進捗バーは見えます。
  • 生成時間: 生成にかかった時間(前回・平均・最短/最長・直近 5 回)を表示します。自動生成でも手動の生成でも計測し、画面を再読み込みしても(アプリを閉じるまで)記録は残ります。「記録を消す」で消せます。
  • 入力補助: 強調(選んでいる文字、なければカーソルのあるタグの重みを、「－」「＋」で 0.1 ずつ上げ下げ。「戻す」で 1.0)と、お気に入り・最近使ったタグ(押すと、入力欄のカーソルの位置に入ります。☆ を押すとお気に入りに入ります)。辞書を取り込んでいないときは、お気に入りと最近使ったタグは使えません(強調は使えます)。
  • タグセット: よく使うタグの組み合わせに名前を付けて覚えます。入力欄でタグを選び(選んでいなければ、カーソルのある段落)、「選んだ文字を取り込む」を押して、名前を入れて「保存」します。覚えたセットを押すと、入力欄のカーソルの位置に、まとめて入ります(「, 」を付ける設定に従います)。「×」で消せます。同じ名前で保存すると、上書きします。50 個までで、名前と文字だけを、このアプリの中に覚えています。
  • プロンプト点検: 入力欄ごと(プロンプト・ネガティブなど)に、タグの数と、重複しているタグを表示します。プロンプトとネガティブの両方に入っているタグ(食い違い)も知らせます。比べるときは、強調の記号(1.2:: や { })、大文字小文字、_ と空白の違いを無視します。数は、タグの数で、NovelAI が数えるトークンの数とは違います。キャラクタープロンプトも数えます(「キャラクタープロンプト1」「キャラクタープロンプト2」…。開いているカードは入力欄から、閉じているカードはプレビューの文字から数えるので、省略されているときは「約」と出ます)。キャラクターごとのネガティブ(除外したい要素)は、カードを開いているときしか画面に出ません。そのため、開いていたときの数と重複を覚えておき、閉じたあとは「前回」として表示します(このタブの間だけ覚えます。一度も開いていないカードは「開くと数えます」と出ます)。パネルのタイトルの横には、重複しているタグの数を表示します(「重複 3」。全部の入力欄の合計です。プロンプトとネガティブの両方にあるタグがあれば、「両方 1」も出ます。ない場合は「重複なし」)。入力欄の中でも、該当のタグに色が付きます(重複しているタグは黄色、プロンプトとネガティブの両方にあるタグは水色。NovelAI が強調したタグに付ける赤い背景と区別するためです)。入力欄の文字そのものは書き換えません。「入力補助の設定」パネルの「プロンプトの重複タグを色で示す」でオフにできます。
  • 入力補助の設定: タグのサジェスト・「, 」を付ける・アンダーバーを空白にする・日本語名で検索・migemo・強調のショートカット・候補の最大数を切り替えます。初めは最小化されています。辞書と日本語訳の取り込み状況も、ここに出ます(取り込みは、メニュー「入力補助」)。
時間は、生成ボタンが押せない状態になってから戻るまでを測ります。画面の作りが変わると、測れないことがあります。

途中から再開・エラーで止まる・終わりの通知

  • 途中から再開: 「自動生成」パネルの「何件目から始める」に番号を入れてから、CSV を読み込みます。番号は CSV のデータ行の順(1 = 最初の行)で、開始するたびに 1 に戻ります。画面に出る行番号と {行} は、元の CSV の行のままです。
  • エラーで止まる: 自動生成の実行中に、画面にエラーの通知(「失敗」「エラー」「しばらくしてから」など)が出ると、そこで止まります。その行は完了に数えません。メニュー「自動生成 → 画面にエラーが表示されたら止める」で切り替えられます(既定はオン)。通知の文言で見分けているので、まれに普通の通知で止まったり、エラーを見逃したりすることがあります。
  • 終わりの通知: 終わったとき、アプリが裏にあれば、通知とタスクバーの点滅(macOS は Dock が跳ねる)で知らせます。メニュー「自動生成 → 終わったとき、窓が裏にあれば通知する」で、通知だけ切れます。
Anlas を消費する場合があります。生成ボタンに Anlas の消費が表示されたら、そこで止まります(「自動生成 → Anlas を消費するときは止める」がオンのとき。既定はオン)。

CSV の形式

UTF-8 の CSV で、1 行目は見出しです。使える列は、次のとおりです(どれも省略できます)。

見出し意味
promptメインのプロンプト
negativeネガティブプロンプト
character1、character2…1 人目、2 人目…のキャラクターのプロンプト(置き換え)
character1+、character2+…画面の今のキャラクター欄の内容を「固定部分」として、その後ろにタグを足す
prompt,negative,character1,character2
"1girl, smile, sunset",lowres,"girl, red hair",
"1boy, forest",,"boy, black hair","girl, blonde"
  • prompt と negative の空欄は、画面に今入っている内容をそのまま使います。列を書かなければ、画面には触りません。
  • キャラクターの列の空欄は、「そのキャラクターは使わない」です。画面のそのキャラクターのプロンプトと UC(除外したい要素)を、どちらも空にします(カードは削除しません。UC は元に戻しません)。画面にそのキャラクターがなければ、何もしません。
  • キャラクターの列を書かなければ、画面のキャラクターには触りません。
  • キャラクターが足りないときは、追加ボタンを押して増やします。追加時の「女性 / 男性 / その他」は、プロンプトの書き出し(girl / woman / female → 女性、boy / man / male → 男性、それ以外 → その他)で選びます。減らしはしません。
  • キャラクターの列の右隣に、見出しが空の列があれば、同じキャラクターのタグとして足します(「, 」でつなぎます)。たとえば、見出しが character1,, なら、1〜3 列目が 1 人目のタグです。
  • character1+ の列は、開始時のキャラクター欄の内容を固定部分として覚え、各行を「固定部分, タグ」にします。終わったら(途中で止めても)固定部分に戻します。同じキャラクターに、character1 と character1+ の両方は書けません。
画面を操作して入力・ボタン押下を行うので、NovelAI の画面が変わると動かなくなることがあります。生成に失敗した行があっても、今は検知せず、次の行へ進みます。

3. 画像の保存

メニュー「保存」で、ダウンロード(画像の保存など)の扱いを選びます。設定は、アプリを閉じても残ります。

  • 毎回、保存先を選ぶ(既定): 保存のたびに「名前を付けて保存」が出ます。
  • 決めたフォルダに自動で保存する: 「保存先フォルダを選ぶ…」で決めたフォルダに、確認なしで保存します。同じ名前があるときは、名前 (1).png のように別名にして、上書きしません。
  • 自動保存をオンにしたとき、保存先が未設定なら、先にフォルダを選びます。保存先が見つからなくなったときは、毎回選ぶ動きになります。
  • 保存できなかったときは、エラーを表示します。
  • 保存できたときは、画面の下の真ん中に、「ファイル名 を フォルダ に保存しました」と、6 秒ほど出ます(自動保存のときも、「名前を付けて保存」のときも、同じです)。ファイル名は、ルールで付け替えたあとの名前や、同じ名前があって連番が付いたあとの名前が出ます。お知らせを押すと、保存したフォルダが開きます。メニュー「保存 → 保存したとき、画面にお知らせを出す」で、オフにできます。

4. ファイル名のルール

メニュー「保存 → ファイル名のルールを設定…」で、保存するファイル名の書式を決めます(拡張子は元のものが付きます)。既定は {元の名前} で、元の名前のままです。設定画面で、保存名の例を確認でき、部品のボタンを押すと書式に入ります。

部品入るもの
{日時} {日付} {時刻}保存した日時(例: 20261112_153045 / 20261112 / 153045)。書式を変えるときは {日時:YYYY-MM-DD_HHmmss} のように「:」のあとに書きます(YYYY 年 / YY 年(下 2 桁) / MM 月 / DD 日 / HH 時 / mm 分 / ss 秒。例: 2026-11-12_153045)
{連番}001、002…(保存のたびに増えます。アプリを閉じても続きます。「連番を 1 に戻す」で戻せます)
{元の名前}もとのファイル名
{seed}シード値
{tag}最初のキャラクタータグ
{characters}全キャラクターのタグ(区切り文字でつなぎます)
{行} {キャラ1} {キャラ2}…自動生成中の保存のときだけ、CSV の行番号とキャラクターのタグ(それ以外は空)

例: {日付}_{tag}_{seed} → 20261112_kagamine_ren_1979642406.png

設定項目

  • 各タグの先頭の文字数: {tag} と {characters} の各タグを、先頭から何文字まで使うか(0 = 制限なし)。
  • 複数キャラの区切り文字: {characters} でつなぐ文字(既定は +)。
  • タグがないときの名前: キャラクターのタグが見つからないときに入る名前(既定は NoChara)。
  • ファイル名に使えない文字(\ / : * ? " < > |)は _ になります。

{seed}・{tag}・{characters} が入る仕組み

  • 自動保存のとき: いったん元の名前で保存して、終わったあとに、PNG 画像の中に入っている情報(NovelAI が書き込む生成情報)を読んで、名前を付け替えます。シードは生成情報から、キャラクタータグはプロンプトと、キャラクター欄のプロンプトから探します。
  • 毎回、保存先を選ぶとき: 保存する前の画像の中身は読めません。{seed} は、元のファイル名の s-数字 から取ります。{tag} と {characters} は「タグがないときの名前」になります。
  • キャラクタータグは、プロンプトのタグ(ベースのプロンプト → キャラクター欄の順)のうち、取り込んだ辞書でキャラクターと分かるものです。辞書を取り込んでいないと、見つかりません。

5. 入力補助(タグのサジェスト)

プロンプト欄にタグを入力すると、取り込んだ辞書から、候補を出します(辞書を取り込んでいないと、出ません)。メインのプロンプト、ネガティブプロンプト、キャラクターのプロンプトで使えます。

キー動き
↑ / ↓候補を選ぶ
Enter / Tab選んだ候補を入れる(入力中のタグが、候補に置き換わります)
Esc候補を閉じる
クリックその候補を入れる
  • 入力中のタグは、カンマの後ろから、カーソルまでです。1.2:: や { [ ( のような強調の記号は、検索に使わず、そのまま残ります。
  • 日本語入力の変換中は、Enter や Tab を横取りしません(変換を確定するキーとして、そのまま使えます)。
  • 候補は、先頭が合うものだけでなく、語の途中が合うものも出します。最大 200 件まで出て、一覧をスクロールできます(「入力補助の設定」パネルの「候補の最大数」で、50 / 100 / 200 / 500 件から選べます)。
  • 候補の並び順は、次のとおりです。同じ順位の中では、投稿件数の多いタグが先です。
    1. タグ名の完全一致
    2. タグ名の前方一致(例: long ha → long hair)
    3. 記号・アンダーバー・空白を無視した前方一致(例: longhair → long hair)
    4. 別名の完全一致、別名の前方一致(例: seifuku → school uniform)
    5. 日本語名(日本語訳を取り込んでいるとき)と、ローマ字で探した日本語名(migemo)
    6. タグ名の部分一致(例: ong ha → long hair)
    7. 記号を無視した部分一致
    8. 別名の部分一致
  • 候補は 2 行で表示します。1 行目にタグ名、2 行目に日本語名(日本語訳を取り込んでいるとき)です。
  • タグ名の文字は、種類で色分けしています(青: 一般 / 赤: 作者 / 紫: 作品 / 緑: キャラクター / 橙: メタ)。タグ名の上にマウスを置くと、種類の名前が出ます。
  • 右端は、投稿件数です。件数を押すと、Danbooru の、そのタグの説明ページ(wiki)を、既定のブラウザで開きます(候補は入りません)。
  • 日本語訳は、機械翻訳のものが混ざっていることがあり、正確とは限りません。
  • ローマ字で日本語を探す(migemo): 日本語訳を取り込んでいるとき、ローマ字で入力すると、日本語名から探します(例: tsuin → ツインテール)。migemo の辞書は、アプリに入っています。

設定(画面の「入力補助の設定」パネル)

次の設定は、画面の右下の「入力補助の設定」パネルで切り替えます(メニュー「View」で表示を出せます)。

  • タグのサジェストを使う
  • 確定したとき「, 」を付ける
  • アンダーバーを空白にして入れる(例: long_hair → long hair)
  • 日本語名で検索する(日本語訳があるとき)
  • ローマ字で日本語を検索する(migemo)
  • 文字の途中にカーソルを置いても候補を出す
  • 入力欄のそばに、強弱・お気に入り・履歴・セットのチップを出す
  • チップを常に表示する(つまみ ≡ をドラッグして動かせる)
  • 強調のショートカット(Ctrl+↑↓で重みを上げ下げ)
  • 候補の最大数(50 / 100 / 200 / 500 件)

文字の途中にカーソルを置いたとき

すでに書いてあるタグの中をクリックしたり、← → ↑ ↓ Home End でカーソルを動かしたりすると、そのタグ全体(前後のカンマまで)を探して、候補を出します。候補を選ぶと、そのタグが丸ごと置き換わります(後ろにすでにカンマがあるときは、カンマを足しません。強調の記号 1.2:: や { } は残ります)。カーソルを動かして出た候補では、↑ ↓ Enter は入力欄で使えます(複数行のプロンプトで、行の移動や改行ができます)。候補を選ぶときは、クリックするか Tab を押します(Esc で閉じます)。文字を打って出た候補は、今までどおり ↑ ↓ Enter Tab で選べます。邪魔なときは、「入力補助の設定」パネルでオフにできます。

分類の絞り込みと色

  • 候補リストの上に、分類ごとのボタン(一般・作者・作品・キャラ・メタ)が出ます。押すと ON / OFF が切り替わり、OFF(取り消し線)にした分類は、候補に出ません。たとえば「作品」を OFF にすると、作品名が候補から消えます。
  • すべて OFF などで候補がなくなったときも、ボタンは残るので、そのまま戻せます。
  • ON / OFF は、アプリを閉じても覚えています。タグの色は、候補リストと同じで、お気に入りと最近使ったタグの文字にも使います(辞書にないタグは色なし)。

お気に入りと最近使ったタグ

  • 候補の左の「☆」を押す(または Ctrl+D)と「★」になり、お気に入りになります。お気に入りは、候補の中で上に出ます。
  • 候補を確定したタグは「最近使ったタグ」として覚え(100 件まで)、お気に入りの次に上へ出ます。
  • 何も打っていないとき(カーソルが空のタグの位置にあるとき)に Ctrl+Space を押すと、お気に入りと最近使ったタグの一覧が出ます。
  • 「入力補助」パネルにも、お気に入りと最近使ったタグが並びます。押すと、入力欄のカーソルの位置に入ります。「消す」で、最近使ったタグを含めて消せます。
  • タグ名だけを、このアプリの中に覚えています。

入力欄のそばのチップ

入力欄にカーソルを置くと(フォーカスすると)、その入力欄の右がわに、30px のチップが縦に並びます。上から「超強」「強」「1.0」「弱」「超弱」「★」「履歴」「セット」です。チップを押しても、入力欄のカーソルや選択は動きません。右に入りきらないときは、入力欄の右端に重なります。入力欄の外へフォーカスが移ると消えます。

カーソルがないとき: 入力欄にカーソル(フォーカス)がない状態では、強弱・お気に入り・履歴・セットは、何も入れません(以前にカーソルがあった場所には入りません)。チップの横に「挿入する場所(入力欄)に、カーソルを置いてから押してください」と数秒出るので、入れたい場所をクリックしてから、もう一度押してください。「常に表示」にしているときに、とくに起きやすい状況です。ショートカットキー(Ctrl+↑ など)も、入力欄にフォーカスがあるときだけ効きます。「入力補助」パネルの強調・お気に入り・履歴のボタンと、「タグセット」パネルの「入れる」も、同じ決まりです。

  • 1.0(強と弱の間): 重みを 1.0 に戻します(強調の記号を外します)。ショートカットキーはありません(Ctrl+0 は、拡大率を戻すキーなので使いません)。
  • 強・弱: いまフォーカスしているタグ(文字を選んでいれば、選んだ文字)の重みを、0.1 上げ下げします。
  • 超強・超弱: 同じく、1.0 ずつ上げ下げします。
  • 重みは -9.9 から +9.9 まで指定できます(1.0 に戻ると記号が外れます)。チップの上の数字が、いまの重みです。
  • ★・履歴: 押すと、お気に入り・最近使ったタグの一覧が開きます(タグ名は分類の色、右は日本語訳)。行を押すと、カーソルの位置(文字を選んでいれば、その上)に入ります。行の ★ / ☆ で、お気に入りの出し入れができます。もう一度チップを押す・Esc・ほかの場所を押すと閉じます。辞書を取り込んでいないときは、一覧は使えません。
  • セット: 「タグセット」パネルで保存したセットの一覧が開きます。行を押すと、セットのタグが、カーソルの位置(文字を選んでいれば、その上)にまとめて入ります。辞書がなくても使えます。

常に表示: 「入力補助の設定」パネルの「チップを常に表示する」をオンにすると、入力欄のフォーカスに関係なく、チップが出続けます。このとき、チップの上のつまみ(≡)をドラッグして、好きな位置に動かせます(窓全体に対する割合で覚えるので、窓の大きさを変えても、同じあたりに付きます)。メニュー「View → パネルを右下にまとめ直す」で、チップの位置も初めに戻ります。強弱のチップは、最後にカーソルを置いていた入力欄のタグにかかります(入力欄にカーソルがない状態では、何も起きません)。

各チップには、ショートカットキーがあります。マウスを載せると、説明に出ます(macOS では Ctrl の代わりに Cmd)。

チップキー
強 / 弱Ctrl+↑ / Ctrl+↓(0.1 ずつ)
超強 / 超弱Ctrl+Shift+↑ / Ctrl+Shift+↓(1.0 ずつ)
★(お気に入り)Ctrl+Shift+F
履歴Ctrl+Shift+H
セットCtrl+Shift+S

一覧を開くキーは、もう一度押すと閉じます(Esc でも閉じます)。入力欄にカーソルがないときは、効きません。「入力補助の設定」パネルの「入力欄のそばに、強弱・お気に入り・履歴・セットのチップを出す」で、オフにできます(オフのときは、一覧を開くキーも効きません)。

強調の補助(Ctrl+↑ / Ctrl+↓)

プロンプト欄で、文字を選ぶか、タグの中にカーソルを置いて Ctrl+↑ を押すと、1.1::タグ:: のように、重みを 0.1 上げます。Ctrl+↓ で 0.1 下げ、1.0 に戻ると記号が外れます(範囲は -9.9〜+9.9)。書き換えたあとも文字は選んだままなので、続けて押せます。カーソルだけのときは、前後のカンマまでを 1 つのタグとして扱います。辞書がなくても使えます。

複数のタグをまとめた強調(1.2::a, b::)は、まとめて選んだときだけ、全体の重みを変えられます。カーソルだけでは、1 つのタグとして扱います。
NovelAI の画面の作りに依存しています。入力欄は、NovelAI の編集欄(ProseMirror)だけに対応しています。画面が変わると動かなくなることがあります。辞書を取り込んだ直後と、ページを読み込み直したあとに、最初の表示まで時間がかかります(辞書が約 14 万件で 1〜2 秒、数十万件になると数秒)。

6. 辞書と日本語訳の入手と取り込み

辞書(タグの一覧)は、アプリには付属していません。次の手順で、自分で入手して取り込みます。辞書は、次の 2 つに使われます。

  • タグのサジェストの候補
  • 保存名の {tag} と {characters}(キャラクター名を見分ける)

辞書を取り込まなくても、アプリは使えます(それらの機能だけが、使えなくなります)。

いちばん簡単な方法: 辞書を作る(Danbooru から取得)

メニュー「入力補助 → 辞書を作る(Danbooru から取得)…」を選ぶと、あなたのパソコンが Danbooru(danbooru.donmai.us)の公開 API に接続して、辞書と日本語訳を作ります。ファイルを探して取り込む必要はありません。

  1. メニューから「辞書を作る(Danbooru から取得)…」を選びます。確認の画面が出るので、内容を読んで「開始」を押します。
  2. 進み具合の窓が出ます。タグの一覧 → 別名 → 日本語名(Wiki)の順に取得します。タスクバーのアイコンにも、進み具合が出ます。
  3. 終わると、「辞書を作りました(全タグ ◯ 件、うちキャラクター ◯ 件)」と出て、すぐに使えます。
  • かかる時間と通信量: 約 10 分、約 30MB です(Danbooru の混み具合によって変わります)。1 秒に 2 回以下の、控えめな速さで取得します。
  • 止める: 進み具合の窓の「停止」か、窓を閉じると、中止します。作り終えるまで、いまの辞書は変わりません(止めても、失敗しても、そのままです)。
  • 取得する内容: 投稿数が 20 件以上のタグ(名前・種別・投稿数)、いまの名前に対応する別名、Danbooru Wiki の日本語名(かなを含むものだけ。複数あれば、候補には最初の 1 つだけを表示し、検索は全部で行います)です。
  • 前の辞書: 作り終えたとき、前の辞書と日本語訳を、同じ場所に .bak として残します。
  • 取り込み済みの日本語訳: そのまま残します。Wiki の日本語名は、ない分だけを補います。
  • 外部のサイトに接続するので、インターネットにつながっている必要があります。取得に失敗したときは、画面に理由が出ます。しばらくしてから、もう一度試してください。
  • 辞書の内容は、Danbooru のデータです(日本語名は、Danbooru Wiki の CC BY-SA のデータを含みます)。作った辞書は、あなたのパソコンの中だけで使われます。このアプリは、辞書を同梱も配布もしません。

以降の「辞書の形式」と「入手方法の例」は、自分でファイルを取り込みたいとき(上級者向け)の説明です。

辞書の形式

「danbooru.csv」の形式です。1 行が「タグ名,種別,件数,別名」の 4 列で、種別が 4 の行がキャラクターです。

hatsune_miku,4,12345,"miku,初音ミク"
1girl,0,6008644,"1girls,sole_female"

入手方法の例

次の 3 つは、どれも、そのまま取り込めることを確認しています(2026-11-15 に、このアプリの取り込みの処理にかけて確認しました)。どれも、このアプリとは関係のない、別の人の配布物です。

1. tagdb-updater(手軽・ログイン不要・毎週更新)

GitHub の PYU224/tagdb-updater(MIT ライセンス)が、Danbooru のタグ一覧を、日本語訳つきで、毎週更新して配布しています。辞書は約 18.8 万タグで、キャラクターは 8 万件(投稿数が多いものから)です。投稿数が少ないキャラクターは、入っていません。

  1. ブラウザで、次のアドレスを開きます。
    https://raw.githubusercontent.com/PYU224/tagdb-updater/main/dist/danbooru.csv
    (配布元のページは https://github.com/PYU224/tagdb-updater の dist フォルダです)
  2. 開いたら、Ctrl + S(Mac は Command + S)で、danbooru.csv として保存します(約 4.9MB)。
  3. 日本語訳は、同じ dist フォルダの danbooru-jp.csv です(https://raw.githubusercontent.com/PYU224/tagdb-updater/main/dist/danbooru-jp.csv)。同じ方法で保存します(約 4.9MB)。

確認した内容: 辞書は 188,123 タグ(キャラクター 80,000 件)、日本語訳は 127,740 件が取り込めました。日本語訳には、Danbooru Wiki の別名と、機械翻訳が混ざります(配布元の説明より)。

2. Civitai の「Danbooru tag complete csv」(ログインが必要)

Civitai の https://civitai.com/models/2018479/danbooru-tag-complete-csv-tagcompleteand で配布されています。ダウンロードには、Civitai のアカウントでのログインが必要です。

  1. ページの「Download」から、danboorutagautocomplete260731.zip(約 17MB。2026-11-15 時点の v2.0)を保存して、展開します。
  2. Full(全部入り)か Lite(軽量)のどちらか 1 つを選び、その中の WebUI フォルダを開きます。ComfyUI-Autocomplete-Plus のフォルダは、形式が違うので使いません。
  3. 辞書は、danbooru_20260731.csv(Full)か danbooru_20260731_lite.csv(Lite)です。日本語訳は、同じ WebUI フォルダの、名前が danbooru_translations_ で始まるファイルです。

確認した内容: Full は 418,412 タグ(キャラクター 170,298 件)、Lite は 318,296 タグ(キャラクター 99,068 件)で、どちらも取り込めました。日本語訳は、約 5.5 万件です。1 つのタグに、複数の訳が、カンマ区切りで入っています(例: 「初音ミク,初音未来,ミクの日…」)。取り込みはでき、どの訳でも検索できます。候補の 2 行目には、最初の 1 つだけを表示します。

3. a1111-sd-webui-tagcomplete の danbooru.csv(古い・小さい)

タグ補完ツール a1111-sd-webui-tagcomplete(MIT ライセンス)が配布している danbooru.csv も、この形式です(2026-11-12 時点で、4 列・約 14 万行・種別 4 が約 4 万件であることを確認しました)。更新はあまり頻繁ではなく、2026-11-12 時点で、最後の更新が 2025 年 1 月でした。

  1. ブラウザで、https://raw.githubusercontent.com/DominikDoom/a1111-sd-webui-tagcomplete/main/tags/danbooru.csv を開きます(配布元のページは https://github.com/DominikDoom/a1111-sd-webui-tagcomplete の tags フォルダです)。
  2. Ctrl + S(Mac は Command + S)で、danbooru.csv として保存します(約 3.5MB)。
  3. アドレスが変わっていたときは、配布元のページで tags フォルダの danbooru.csv を探してください。

この辞書には、日本語訳は入っていません。

配布元のアドレスは、変わることがあります。取り込めないときは、各配布元のページで、最新のファイルを探してください。

辞書と日本語訳は、それぞれの配布元のライセンスに従って使ってください。MIT ライセンスのものは、著作権表示を残す条件があります。Civitai のページは、ライセンスの欄に「CircleStone Non-Commercial License v1.2」、説明文には「自由に利用・改変・再配布可能」と、表記が分かれています(2026-11-15 時点)。使う前に、ページを確認してください。取り込んだ辞書は、あなたのパソコンの中だけで使われます。このアプリは、辞書を同梱も配布もしません。

取り込み方

  1. メニュー「入力補助 → 辞書を取り込む…」を選びます。
  2. 保存した辞書の CSV(danbooru.csv など)を選びます。
  3. 「辞書を取り込みました(全タグ ◯ 件、うちキャラクター ◯ 件)」と出れば、完了です。メニューに「辞書: 取り込み済み(◯ 件)」と表示されます。
  4. 不要になったら、「辞書と日本語訳を削除」で消せます(元の CSV は消えません)。
  5. 以前の版で取り込んだ辞書(キャラクターだけのもの)は、キャラクターの判定にだけ使えます。サジェストを使うには、もう一度、取り込み直してください。

日本語訳(任意)

日本語訳を取り込むと、候補に日本語名が出て、日本語(と、ローマ字)で探せます。取り込めるのは、「英語のタグ,日本語」の 2 列の CSV です(2 列目が数字の、3 列の古い形式なら、3 列目を使います)。

school_uniform,制服
hatsune_miku,初音ミク
  • 日本語訳は、辞書とは別のファイルです。上の「入手方法の例」の、tagdb-updater の danbooru-jp.csv(約 12.8 万件)か、Civitai の danbooru_translations_ で始まるファイル(約 5.5 万件。複数の訳がカンマ区切りで入っています)が、そのまま取り込めます。上のタグ補完ツールの配布元(https://github.com/DominikDoom/a1111-sd-webui-tagcomplete)の説明(README)にも、日本語訳の一覧があります。
  • 配布されているファイルが、上の形式かどうかは、取り込む前に確認してください(中身をメモ帳などで開くと分かります)。形式が違うと、「日本語訳が見つかりません」と出て、取り込めません。
  • メニュー「入力補助 → 日本語訳を取り込む…」で選びます。件数が、メニューに出ます。
  • 1 つのタグの訳が「A,B,C」のようにカンマで区切られているときは、候補には最初の 1 つ(A)だけを表示します。検索は、A・B・C のどれでもできます。数字の間のカンマ(40,000)と、カンマのあとに空白が続くもの(若い, 浸透する)は、1 つの訳として扱います。
  • 日本語訳は、それぞれの配布元のライセンスに従って使ってください。

仕組みと、できないこと

  • 取り込むときに、全タグ(名前・種類・投稿件数・別名)を、このアプリ専用の保存場所に保存します。キャラクターの判定には、種類が 4 のタグと、その別名を使います。別名は、kagamine_ren → kagamine_len のような言い換えです。/hm のような略記や、キャラクター以外のタグと同じ名前の別名は、使いません。
  • タグは、前後の空白・強調の記号・大文字小文字を無視して、空白を _ にそろえてから、辞書と比べます。
  • 辞書は、あるときまでの一覧です。新しいキャラクターは、辞書を更新して取り込み直すまで、見つかりません。a1111-sd-webui-tagcomplete の danbooru.csv は、2026-11-12 時点で、最後の更新が 2025 年 1 月です(更新はあまり頻繁ではありません)。新しいキャラクターを使うときは、毎週更新される tagdb-updater など、新しい辞書(同じ 4 列の形式)を取り込んで、差し替えられます。
  • プロンプトに、辞書にない名前を書いたときは、見つかりません(その場合は、「タグがないときの名前」になります)。

7. 拡張機能

展開済みの Chrome 拡張機能(manifest.json があるフォルダ)を、起動時に読み込めます。

  1. メニュー「Extensions → 拡張機能フォルダを開く」で、フォルダを開きます。
  2. 拡張機能のフォルダを、そのまま中に置きます。
  3. アプリを再起動します。
  4. 設定画面がある拡張機能は、メニュー「Extensions → 設定を開く: (拡張機能の名前)」で、別ウィンドウに開けます(拡張機能自身のボタンでは開けません)。
  • 拡張機能は、このアプリに付属していません。各自で入手して、それぞれのライセンスに従ってください(再配布や改変が禁止されているものもあります)。
  • .crx や Chrome ウェブストアからのインストールには対応していません。
  • Electron が対応している拡張機能の API は、一部だけです。chrome.downloads・chrome.notifications・chrome.tabs.create などは使えません。これらを使う拡張機能は、その部分(または全体)が動きません。動かない拡張機能もあります。
  • 拡張機能は、NovelAI のページの中で動き、ログイン情報にアクセスできます。信頼できるものだけを入れてください。

8. 困ったとき

  • 自動生成が止まる・動かない: 表示されたエラーの文を見てください。画面が変わったときは、メニュー「自動生成 → 画面の構造を調べる(調査用)」で、画面の入力欄・ボタン・キャラクター欄の構造を表示・コピーできます(入力した文字は含みません)。
  • 生成が、ブラウザ版より遅い: 生成の設定が、ブラウザ版と別になっています。モデル・ステップ数・サンプラー・サイズなどを、そろえてください。
  • ×で閉じられない: 生成後などに確認が出ます。「閉じる」を選んでください。
  • Windows で「SmartScreen」の警告が出る: 「詳細情報 → 実行」で開けます。macOS で開けないときは、アプリを「右クリック → 開く」で開きます(署名をしていないためです)。
  • 設定の場所: アプリの設定(保存方法・ファイル名のルール・連番)は、アプリのデータフォルダの settings.json に、取り込んだ辞書は character-dictionary.json に保存されます。拡張機能のフォルダも、同じデータフォルダの中の extensions です。
